# FileDrop Local

Локальный обмен файлами между компьютером и телефоном или другим устройством через обычный браузер.

FileDrop запускает временную папку обмена и небольшой HTTP-сервер на компьютере. Программа показывает QR-код и адрес, а подключившееся устройство открывает веб-интерфейс без установки отдельного приложения. Это удобно для быстрого обмена фото и документами между Windows, Linux, iPhone и Android в одной домашней сети.

## Возможности

- отправка одного или нескольких файлов через браузер;
- скачивание файлов с компьютера и пакетная загрузка ZIP;
- предпросмотр изображений и текстовых файлов;
- общая заметка для устройств в текущей сессии;
- QR-код и копирование адреса подключения;
- drag-and-drop на компьютере;
- выбор сетевого адреса перед запуском;
- временная папка, которая удаляется после закрытия приложения;
- постоянная папка как отдельная настройка;
- потоковая передача файлов без загрузки всего файла в память;
- Windows EXE через PyInstaller.

## Быстрый запуск Windows

Скачайте `FileDrop.exe` из раздела Releases и запустите его. Установка не требуется.

1. Выберите адрес компьютера, доступный телефону или другому устройству в локальной сети.
2. Нажмите **Запустить FileDrop**.
3. Отсканируйте QR-код или откройте показанный адрес в браузере.
4. После обмена закройте программу — временные файлы будут удалены.

Если страница не открывается, проверьте, что устройства подключены к одной сети и Windows Firewall разрешает входящие подключения для FileDrop.

## Запуск из исходников

Нужны Python 3.10+ и рабочий Tkinter.

```bash
python -m venv .venv

# Windows
.venv\\Scripts\\activate

# Linux/macOS
source .venv/bin/activate

pip install -r requirements.txt
python Main.py
```

На Linux может потребоваться системный пакет Tkinter, например `python3-tk`.

## Сборка EXE локально на Windows

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
.\build-windows.ps1
```

Готовый файл появится в `dist\\FileDrop.exe`.

В репозитории также есть workflow `.github/workflows/windows-release.yml`. Он собирает Windows x64 EXE на GitHub Actions при публикации тега вида `v2.0.0` и прикрепляет архив к GitHub Release.

## Как работает хранение

По умолчанию используется отдельная временная папка `filedrop-*`. Она создаётся при запуске и удаляется при завершении приложения. В режиме постоянного хранения можно выбрать каталог в настройках; тогда файлы сохраняются в выбранном месте.

## Состав проекта

```text
Main.py                 точка входа
filedrop/gui.py         desktop-интерфейс
filedrop/server.py      встроенный HTTP-сервер
filedrop/handler.py     маршруты и API
filedrop/multipart.py   потоковый разбор загрузки
filedrop/archive.py     ZIP-скачивание
filedrop/network.py     сетевые адреса и размеры
filedrop/paths.py       пути ресурсов и данных
filedrop/assets.py      веб-ресурсы
filedrop/web/           мобильный веб-интерфейс
tests/                  smoke-тесты HTTP-сценария
```

FileDrop рассчитан на кратковременное использование в доверенной домашней или рабочей локальной сети. Это не облачное хранилище и не постоянный файловый сервер.
