# Changelog

## 2.0.0 — 2026-09-11

- компактный двухшаговый desktop-интерфейс без прокрутки главного окна;
- отдельные окна для файлов сессии, заметок и настроек;
- выбор адреса локальной сети перед запуском;
- спокойная светлая цветовая система и обновлённый мобильный веб-интерфейс;
- контрастный QR-код и кнопка открытия FileDrop в браузере;
- временное хранилище с очисткой после завершения приложения;
- потоковая загрузка и скачивание файлов через встроенный HTTP-сервер;
- автоматическая Windows-сборка через GitHub Actions.
